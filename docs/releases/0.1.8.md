# RanCount 0.1.8

Android 版本：0.1.8，构建号：2019。

- AI 对账改为设置、流水、审核三个步骤，每步保留明确的主操作和完成条件，草稿自动保存。
- 统一对账页面与弹窗的卡片、按钮和输入框边框。按账户添加截图并预览；实际余额、余额时间和流水完整性分别填写。
- 期间选择支持近 7 天、近 30 天、本月和上月，明确显示开始和结束日期。交易及余额时间通过日期和时分秒选择，不再要求手输时间格式。
- 审核页分开显示账户余额、待检查事项和修改建议。建议展示原记录、修改内容及流水依据，勾选后查看余额预览。
- 编辑建议时明确区分支出、收入、转账和退款，金额统一填正数；保存建议后仍需确认应用才会修改账本。
- 资产管理标题栏加号右侧的推广入口替换为 AI 对账，移除资产列表顶部的对账卡片。

验证：定向静态分析及 Android 发布构建。前端测试、浏览器检查和交互验收未执行，由用户负责。沿用现有对账存储与 Cloud 同步协议，无新增数据库迁移。
