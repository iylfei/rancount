# RanCount 0.1.6

Android 版本：0.1.6，构建号：2017。

- 截图入账后直接通知主页面读取已提交的本地数据，清除旧明细缓存。
- 资产页显示本月待还款，已配置的本月计划全部还清后显示下月；点击可查看任意年月。
- 信用卡、贷款及透支账户支持月度还款计划。同一金额可批量分配到连续或任意月份，包括跨年月份。
- 当月转入还款自动抵扣计划金额；可手动标记在外部完成的还款，并取消标记或修改计划。
- 还款计划随账户云同步，也随 JSON 备份和配置导出保存。
- 修复智能记账设置中开启状态的开关滑块与轨道同色问题。

配套 Cloud 数据库迁移：`0021_account_repayment_schedule`，仅新增可空账户字段。前端交互由用户在更新后检查。
