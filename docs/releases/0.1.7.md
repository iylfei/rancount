# RanCount 0.1.7

Android 版本：0.1.7，构建号：2018。

- 资产页新增 AI 对账，可在同一次对账中选择支付宝余额、微信零钱、银行卡、现金等多个日常资金账户，按账户添加多张近期流水截图。
- 提取流水时间、变动金额和交易后余额，合并重叠截图；不完整的识别结果可检查和编辑，也可手动补充现金等外部流水。
- 跨个人账本核对记录，综合分析漏记、错账户、金额或日期错误、转账和退款，生成带依据及修改前后内容的建议。
- 支持编辑、选择建议和查看各账户余额预览。确认后整批应用；记账或同步数据改变时要求重新分析。保留修改记录并支持撤销，遇到后续编辑时停止覆盖。
- 期间流水差额与期初已有差额分别展示，不自动校准余额。截图和对账草稿保存在本机，可在对账列表删除未应用或已撤销的草稿。
- 信用卡等账户详情中的月度还款计划与上方概览卡增加间距。

识别使用截图记账的视觉配置，综合分析使用 AI 文本服务配置。对账首版不包含信用卡、贷款和估值资产，跨币种转账需要另行处理。确认后的交易沿用现有 Cloud 同步协议，无新增服务端迁移。

验证：对账服务与存储逻辑测试、相关记账回归测试、定向静态分析和 Android 发布构建。前端交互由用户在更新后检查。
