# RanCount 0.1.9

Android 版本：0.1.9，构建号：2020。

- AI 对账的截图识别与综合分析统一使用截图记账设置中的模型、地址和密钥，可直接复用多模态模型，无需另外配置文本模型。
- 移除逐账户的流水完整性勾选项。未添加截图或手动流水的账户默认按期间无变动核对；上传但无法识别的资料仍提示检查，不当作零流水。
- 信用卡、花呗等可记账负债账户可以参与多账户对账。填写当前总欠款，包含未出账部分；消费增加欠款，还款和退款减少欠款。还款通过资金账户至负债账户的转账核对。
- 负债账户的输入、流水方向与审核报告统一显示欠款口径。历史差额仍单独列出，未经补证不调整余额。

验证：定向静态分析、对账存储与计算及 AI 请求单元检查、Android 发布构建。未执行前端测试、浏览器检查和交互验收；真实 AI 服务调用由用户测试。沿用现有数据库和 Cloud 同步协议。
