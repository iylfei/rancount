# RanCount 0.1.0

Android 液态玻璃主题更新，构建号 2011。

## 新增与改进

- Android 默认启用液态玻璃外观，统一导航、记账键盘、主要页面、弹窗和截图记账窗口；支持浅色、深色及跟随系统。
- 新增经典外观切换、自动／简化玻璃、界面动效及触感反馈设置；这些设置仅保存在本机，支持配置导入导出。
- 保留经典主题色与头部皮肤，切回经典后恢复；iOS 保持经典界面。
- 优化按钮按压反馈、记账分段选择、账户选择与键盘布局。

## 修复

- 修复玻璃渲染时底部导航栏和弹窗内容不可见的问题。
- 调整筛选弹窗配色，补齐筛选项边框，改善玻璃圆角边缘的锯齿。
- 放大明细弹窗文字，让弹窗随内容收缩，减少底部空白。
- 修复页面切换背景先暗后亮、分类详情跳转文字重叠的问题。
- 修复记账键盘快速连续输入运算符和数字时的计算错误。

## 下载与升级

- `rancount-0.1.0-arm64-v8a.apk`：适用于大多数现代 Android 手机。
- `rancount-0.1.0-universal.apk`：包含 arm64-v8a、armeabi-v7a 和 x86_64。
- `SHA256SUMS.txt`：安装包的 SHA-256 校验值。

最低支持 Android 6.0。应用 ID 仍为 `com.tntlikely.beecount`，继续使用此前个人预览版的本地签名，可覆盖升级使用同一签名的版本。上游官方版本的签名可能不同；遇到签名冲突时，请先导出数据，不要直接卸载。

本次仅发布 Android APK，不包含 iOS 安装包。GitHub Release 不会自动接入应用内更新检查；应用内更新继续使用设备所配置的 BeeCount Cloud 更新源。

## 验证范围

已完成相关静态分析、外观配置和截图草稿逻辑检查、记账键盘计算回归检查，以及 Android Release 构建。已在连接的 Android 手机检查主要页面、弹窗、主题切换及页面过渡。设备帧率、耗电、触感体验和其他 GPU 的兼容性仍需进一步验证。

## 从源码构建

使用 `.fvmrc` 固定的 Flutter 3.32.8，执行 `flutter build apk --release --flavor prod`。应用版本及构建号由 `pubspec.yaml` 提供。RanCount 自有发布使用 `rancount-v*` 标签，上传本地验证且签名一致的 APK；该标签不触发继承的上游自动发布流程。
